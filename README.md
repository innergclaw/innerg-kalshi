# InnerG Kalshi | Prediction AI Training

> KALSHI trading interface for InnerG Intel

---

## What This Is

A paper trading training interface for KALSHI prediction markets. Built with InnerG branding — black & green, terminal aesthetic.

---

## Features

- **15-minute & 5-minute BTC trading** — time-boxed predictions
- **Paper trading mode** — practice without real money
- **Real-time orderbook** — YES/NO bid visualization
- **Performance tracking** — P&L, win rate, trade history
- **Live countdown timer** — candle close synchronization
- **Terminal log** — system activity monitoring

---

## Tech

- Static HTML/CSS/JS
- No backend required (paper trading runs in browser)
- KALSHI API ready (authentication needed for live trading)
- GitHub Pages compatible

---

## Usage

1. Open `index.html` in browser
2. Select timeframe (5m / 15m / 1h)
3. Choose YES (price up) or NO (price down)
4. Click "Place Trade"
5. Wait for candle close to see result

---

## Live Trading

To connect to real KALSHI markets:

1. Get API key from [kalshi.com](https://kalshi.com)
2. Add authentication headers to API calls
3. Switch from paper trading to live mode
